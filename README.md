
# Sistema de E-commerce em Java

Sistema acadêmico de e-commerce desenvolvido em Java durante a graduação em Engenharia de Software na UFMS.

## Objetivo
Aplicar conceitos de Programação Orientada a Objetos na construção de um sistema de gerenciamento de produtos e carrinho de compras.

## Tecnologias
- Java
- Programação Orientada a Objetos (POO)
- Apache Maven
- NetBeans

## Conceitos aplicados
- Classes e objetos
- Encapsulamento
- Construtores e métodos
- Interfaces
- Coleções
- Tratamento de exceções

## Funcionalidades
- Cadastro e gerenciamento de produtos
- Controle de estoque
- Carrinho de compras
- Organização de itens e quantidades

## Sobre o projeto
Projeto acadêmico desenvolvido para exercitar a organização de código, a modelagem de classes e a resolução de problemas utilizando Java.
